# IHB-X5 代码项目总结

## 项目概述
这是一个使用C++开发的机器人关节控制系统，主要通过CAN总线接口控制各种电机和传感器。该系统支持伺服电机、肌肉关节（气动）、步进电机等多种驱动方式，并使用霍尔传感器和力传感器进行反馈控制。

## 核心组件

### 1. CanDriver (ihb_cpp/lib/libsockcanpp/include/CanDriver.hpp)
- 提供CAN总线通信功能
- 基于SocketCAN实现
- 支持消息发送和接收
- 支持过滤器设置
- 线程安全设计

### 2. 电机控制

#### MuscleJoint (ihb_cpp/include/muscle_joint.h)
- 气动肌肉关节控制
- 支持设置压力（setPressure）
- 支持设置角度（setAngle）
- 支持PID闭环控制（setAnglePID）
- 支持变刚度控制（setStiffness）

#### ServoMotorJoint (ihb_cpp/include/servo_motorJoint.h)
- 伺服电机控制
- 支持位置控制（setPositonWithSpeedLimit）
- 支持角度读取（readAngle）
- 减速比设置（Ratio = 8）
- 通过CAN总线进行通信

#### StepperMotorJoint (ihb_cpp/include/stepper_motor_joint.h)
- 步进电机控制
- 支持高度控制（setHeight）
- 支持零点重置（reZeo）

### 3. 传感器系统

#### HallSensors (ihb_cpp/include/hall_sensors.h)
- 霍尔传感器读取
- 支持获取角度值
- 支持零点设置
- 多线程实现数据读取

#### ForceSensors (ihb_cpp/include/force_sensors.h)
- 力传感器读取
- 支持多通道力数据获取
- 提供不同配置选项

### 4. 控制算法
- 使用MiniPID库实现PID控制
- 支持前馈控制

## 主程序功能 (demo/serAngle.cpp)

主程序demo/serAngle.cpp展示了系统的基本使用方法：

1. 初始化四个伺服电机和四个肌肉关节
2. 创建CAN通信线程接收消息（receiveCanFramesExample）
3. 创建角度处理线程（progressAngle）
4. 初始化传感器（hallSensors.start()）
5. 发送电机控制命令（setPositonWithSpeedLimit）
6. 循环读取和显示电机角度

主程序中还包含一些被注释掉的高级功能，如：
- 数据记录（logW函数）
- 肌肉关节PID控制

## 通信协议
系统使用CAN总线通信，每个设备都有唯一的CAN ID：
- 伺服电机ID: 0x141-0x144
- 各种传感器和执行器也有各自的ID范围

## 系统特性
1. 多线程设计
2. 实时控制
3. 模块化架构
4. 支持多种传感器和执行器

## 使用示例
```cpp
// 初始化伺服电机
ihb::ServoMotorJoint ser1(1);
// 设置伺服电机位置和速度限制
ser1.setPositonWithSpeedLimit(10 * 100, 120);
// 读取伺服电机角度
float angle = ser1.MAngle();

// 初始化肌肉关节
ihb::MuscleJoint muscle1(0);
// 设置肌肉关节压力
muscle1.setPressure(0, 0, 0, 0);
// 设置肌肉关节角度PID控制
muscle1.setAnglePID(-8, 8);
```
